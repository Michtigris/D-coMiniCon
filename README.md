# DécoMiniCon

Petite fenêtre de conversation pour deux PC Windows.

## Installer

Le fichier à envoyer est `build/Decominicon-Setup-0.1.0.exe`. C’est l’installateur : ton ami double-clique dessus, et c’est lui qui installe l’application. Il ne faut pas envoyer le dossier du projet.

1. Double-clique dessus.
2. Si Windows affiche « Windows a protégé votre PC », clique **Informations complémentaires**, puis **Exécuter quand même**. L’application n’est pas signée.
3. Suis l’assistant. Un raccourci DécoMiniCon apparaît sur le bureau.

Même fichier pour toi et pour ton ami.

## Se retrouver

1. L’un de vous clique **Héberger le salon sur ce PC** et choisit un pseudo.
2. Si Windows demande l’accès au réseau, autorise les réseaux privés.
3. Copie l’adresse affichée (du type `http://192.168.x.x:3847`) et envoie-la à l’autre.
4. L’autre colle cette adresse, choisit son pseudo, puis entre dans le salon.
5. Demande en ami, accepte, puis **Lier**. La fenêtre devient le chat.
